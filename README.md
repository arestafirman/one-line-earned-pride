> After eleven years of night shifts, she folded her uniform for the last time, set it on the chair, and walked out into the morning light.

The program (`main.ts`, Node 22, no dependencies) writes that single line to `/output/entry.txt` — 137 characters, one line, no trailing newline. It runs fully offline: only `node:fs`, no network, no randomness, no clock.

## Run
